# Siege engines

The town's catapult and ballista, rolled out against the Behemoth of the Rift
(`client/js/world/siege3d.js`), and their wrecks, are from Kenney's Castle Kit (2.0),
<https://kenney.nl/assets/castle-kit>: `siege-catapult.glb`, `siege-ballista.glb`,
`siege-catapult-demolished.glb` and `siege-ballista-demolished.glb` from its `Models/GLB format`.
Each is as the kit has it but for its colour picture (the kit's `Textures/colormap.png`, which each
of them reads from beside it), put inside it. CC0: see `License.txt` here.
