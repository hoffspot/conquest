Sound Studio

Every sound Pellagos makes: what it is, when the game plays it, where it comes from. Played here as the game plays it.

Sound starts on a tap: browsers want one first.

Each sound's description is in client/js/audio/catalog.js; recordings and their sources in client/js/audio/recorded.js (made by npm run build:sounds); the made ones in client/js/audio/synth.js.
